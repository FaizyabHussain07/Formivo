# Formivo — Brand Identity System

**Document:** `16-brand-identity.md`  
**Product:** Formivo  
**Status:** Final Version 3.0 Brand Direction  
**Purpose:** Define the complete visual, verbal, and product identity of Formivo so the marketing website, dashboard, documentation, emails, social assets, favicon, OG images, and future brand materials all feel like one professional product.

---

# 1. Brand Foundation

## 1.1 Brand Name

**Formivo**

Always write the brand as:

> Formivo

Do not write:

- FORMIVO
- FORMIVO SaaS
- FormIvo
- Formivo.io
- Formivo App

The lowercase/uppercase treatment may change visually in a logo, but the official written brand name is **Formivo**.

---

# 2. Brand Positioning

## 2.1 Core Positioning

> **Formivo is the lead infrastructure layer for existing website forms.**

Formivo helps developers and agencies connect existing website forms to a professional backend for capturing, managing, analyzing, and sharing leads with clients.

Formivo is not primarily a form builder.

The core V1 value is:

> **Connect the forms you already have. Turn submissions into organized leads. Give clients visibility.**

---

> **Formivo connects existing website forms to a professional lead management and client dashboard.**

---

# 6. Short Description

> Formivo gives developers and agencies a simple way to connect website forms, capture submissions, manage leads, track performance, and give clients a clean dashboard without building a backend from scratch.

---

# 7. Extended Description

> Formivo is a developer-first lead infrastructure platform for websites and agencies. Connect an existing form to Formivo, receive submissions through a secure endpoint, manage them as leads, understand performance through analytics, and give clients access to a dedicated dashboard.
>
> Instead of rebuilding form handling, databases, lead management, and client visibility for every project, developers can use Formivo as the backend layer that connects the pieces together.

Formivo should feel:

### 1. Reliable

The product handles important business leads.

Every interaction should communicate stability and trust.

### 2. Precise

Interfaces should feel intentional.

Avoid unnecessary decoration.

### 3. Developer-first

### 4. Professional

Formivo should look suitable for serious agencies and businesses.

### 5. Modern

The product should feel current without chasing design trends.

The product should remain understandable to developers and agency owners without feeling overly enterprise-oriented.

### 7. Calm

Formivo should reduce complexity rather than create visual noise.

# 10. Visual Identity Direction

## Core Visual Concept

Formivo's identity should communicate:

> **Structure → connection → flow → leads**

The visual language should subtly reference the idea of multiple form fields flowing into an organized system.

The brand should NOT literally use a generic document icon or generic form icon.

---

# 11. Logo Concept

## 11.1 Primary Logo Concept

The Formivo logo should use a **custom geometric "F" flow mark**.

The mark should visually combine:

- A form structure
- Connected fields
- A directional flow
- The letter **F**

Conceptually:

```text
Form fields
┌──────────┐
│ ──────── │
│ ──────── │
│ ──────── │
└────┬─────┘
     │
     └──────→ Lead
```

The final symbol should abstract this concept rather than literally draw a form.

---

# 12. Logo Mark Construction

The icon should be built from a small number of geometric elements.

Recommended construction:

- Three horizontal structural elements
- One vertical connecting element
- One subtle directional connection
- Consistent stroke/geometry
- Slightly rounded corners
- Strong negative space
- No unnecessary detail

The symbol should resemble an abstract **F** when viewed normally.

At smaller sizes, the icon must remain recognizable without the wordmark.

---

The Formivo mark should be:

- Geometric
- Simple

- Recognizable
- Flat

# 15. Logo Clear Space

Minimum clear space around the logo should equal the height of the internal icon's primary stroke unit.

Simplified implementation rule:

> Keep at least **25% of the logo width** as visual breathing room around the complete logo.

Never place the logo directly against:

- Text
- Buttons
- Borders
- Screenshots
- Other logos
- Busy imagery

---

# 16. Logo Minimum Size

Recommended minimum sizes:

### Digital

Symbol:

- Minimum: 20px
- Preferred: 24px+

Horizontal logo:

- Minimum width: 96px
- Preferred: 120–160px

### Print

Minimum symbol:

- 8mm

Never scale the complete logo so small that the mark becomes visually unclear.

---

# 17. Logo Misuse

Never:

- Stretch the logo
- Compress the logo
- Rotate the logo
- Add shadows
- Add random gradients
- Change individual logo elements
- Outline the logo unnecessarily
- Put the logo inside a random circle
- Add emojis
- Add decorative effects
- Change proportions
- Use low-resolution versions

# 26. Gradient Rules

Gradients are **not part of the core dashboard identity**.

Do not use gradients for:

- Dashboard backgrounds
- Cards
- Buttons
- Navigation
- Tables
- Forms

A very subtle teal-to-transparent atmospheric gradient may be used in marketing sections only when it improves visual hierarchy.

Never use:

- Purple-blue AI gradients
- Rainbow gradients
- Neon gradients
- Large gradient blobs

Do not:

- Weight
- Spacing
- Contrast

---

# 31. Border Radius

Formivo should use restrained rounding.

Recommended:

```text
xs: 4px
sm: 6px
md: 8px
lg: 12px
xl: 16px
```

Primary dashboard components should generally use:

```text
8px–12px
```

Marketing cards may use:

```text
12px–16px
```

Avoid:

```text
24px+
```

unless there is a deliberate marketing reason.

Formivo should not look like a collection of floating pills.

---

# 32. Shadows

Use shadows sparingly.

Preferred:

- Subtle dropdown shadow
- Modal shadow
- Elevated popover shadow

Avoid:

- Heavy card shadows
- Neon shadows
- Colored shadows
- Glow effects everywhere

Borders should do most of the structural work.

---

# 33. Iconography

Use a consistent outline icon system.

Recommended implementation:

**Lucide Icons**

Characteristics:

- 1.75–2px stroke
- Rounded line caps
- Simple geometry
- Consistent optical sizing

Icons should support the interface rather than become decorative artwork.

# 42. Motion Identity

Formivo motion should feel:

> **Fast, subtle, functional.**

Recommended durations:

```text
Micro interaction: 120–160ms
UI transition:      160–220ms
Modal:              180–240ms
Page transition:    200–300ms
```

Use easing similar to:

```text
ease-out
```

Motion should communicate:

- State changes
- Navigation
- Loading
- Confirmation
- Hierarchy

Never animate elements simply because animation is possible.

---

# 43. Loading States

Use:

- Skeletons
- Progress indicators
- Small spinners

Avoid:

- Full-screen decorative loaders
- Long branded animations
- Fake progress bars
- Excessive shimmer

---

# 44. Empty States

Empty states should be useful.

Structure:

```text
Title
Short explanation
Primary action
Optional secondary action
```

Example:

> No forms yet  
> Connect your first website form to start receiving leads.  
> [Create form]

Do not use generic:

> "Oops! Nothing here!"

---

# 45. Error Language

Formivo errors should be:

- Clear
- Specific
- Calm
- Actionable

Bad:

> Something went wrong!!!

Good:

> We couldn't create the form. Check your connection and try again.

Technical errors should expose a request ID when appropriate.

---

# 75. Logo File Rules

Logo SVGs must:

- Be optimized
- Use valid viewBox
- Have no unnecessary metadata
- Have no embedded raster images
- Work on light backgrounds
- Work on dark backgrounds
- Preserve proportions

Do not use screenshot-based logos.

---

# 76. Brand Accessibility

All brand implementation must maintain WCAG-conscious contrast.

Do not use the lighter mint color as small text on white.

Avoid low-contrast combinations.

Primary interactive elements must remain clearly identifiable without relying only on color.

Status indicators should use:

```text
Color + text/icon
```

not color alone.

---

# 77. Responsive Brand Behavior

The identity must remain consistent across:

### Desktop

Full logo + navigation.

### Tablet

Compact navigation where necessary.

### Mobile

Symbol or compact logo where space is limited.

The brand should never become unreadable because the complete wordmark is forced into a tiny header.

---

# 78. Marketing vs Product Branding

Marketing can be slightly more expressive.

Product UI must remain restrained.

```text
Marketing
More whitespace
More visual storytelling
Subtle gradients allowed
Larger typography

Dashboard
More density
More data
Less decoration
No unnecessary gradients
Compact typography
```

Both must clearly belong to Formivo.

# 79. AI Coding Agent Brand Rules

Any AI coding agent working on Formivo must follow these rules.

### Rule 1

Never invent a new color when an existing design token applies.

### Rule 2

Never introduce a purple AI gradient.

### Rule 3

Never add emojis to navigation or primary UI.

### Rule 4

Never add random illustrations.

### Rule 5

Never create fake customer logos, testimonials, statistics, or integrations.

### Rule 6

Never use excessive glassmorphism.

### Rule 7

Never turn every section into a rounded card.

### Rule 8

Never use excessive shadows.

### Rule 9

Never create oversized UI elements without a UX reason.

### Rule 10

Always prioritize hierarchy, whitespace, accessibility, and usability.

### Rule 11

Use Formivo's teal as an accent, not as the background for everything.

### Rule 12

The interface must feel intentionally designed rather than generated from a generic SaaS template.

# 81. Final Brand Definition

Formivo is:

Its visual identity is:

> **Dark ink + professional teal + neutral surfaces + precise typography + geometric flow.**

Its personality is:

> **Reliable. Precise. Technical. Modern. Calm.**

Its primary tagline is:

> **Forms to leads. Leads to clients.**

> **Connect your forms. Capture your leads. Give clients their dashboard.**

> **Structured fields flowing into an organized lead system.**

# 82. Final Brand Principle

The most important rule for Formivo's identity is:

> **Make complexity feel organized.**

Formivo is solving a messy workflow:

```text
Website
   ↓
Form
   ↓
Submission
   ↓
Backend
   ↓
Lead
   ↓
Developer
   ↓
Client
```

The brand should make this feel simple.

Every visual decision should reinforce:

```text

Capture.
Organize.
Share.
```

Formivo should never try to look louder than the problem it solves.

It should look like the product people trust to handle the work quietly in the background.

# 83. Final Implementation Instruction

When implementing Formivo, treat this document as the **brand source of truth**.

If an existing component conflicts with these guidelines:

1. Preserve working functionality.
2. Preserve accessibility.
3. Preserve existing architecture.
4. Refactor visual styling toward this brand system.
5. Do not introduce competing visual systems.

Do not redesign Formivo randomly on a page-by-page basis.

The entire product must feel like one coherent system.

**Build Formivo as a recognizable product brand, not as another generated SaaS dashboard.**
